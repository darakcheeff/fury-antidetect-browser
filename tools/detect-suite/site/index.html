Добавить свою машину в каталог Fury

Тридцать секунд. Ничего не устанавливается, никуда ничего не отправляется само.

Каталог персон Fury — это настоящие компьютеры: их видеокарта, экран, шрифты, голоса синтезатора. Чем больше в нём разных машин, тем больше толпа, в которой можно спрятаться. Ваша машина в нём — файл с вашим ником, навсегда.

Как

  1. Откройте пробник в обычном Google Chrome — не в Fury, не в другом антидетекте. Персона должна описывать машину, а не браузер поверх неё.
    Открыть пробник
  2. Нажмите «Снять отпечаток», затем «Скачать JSON». Файл останется у вас — страница ничего не отправляет.
  3. Откройте форму и перетащите файл в поле — GitHub прикрепит его сам. Напишите, что это за машина.
    Открыть форму

Дальше робот превратит файл в персону, проверит её и откроет pull request. Вы увидите ссылку в своём issue.

Это отпечаток вашего компьютера. Опубликовав его, вы публикуете то, как ваш компьютер выглядит для любого сайта. Снимайте с машины, на которой не живут ваши рабочие аккаунты. Персональных данных в файле нет — ни имени, ни адресов, ни истории; но серийного номера видеокарты и набора шрифтов достаточно, чтобы узнать машину.

Что нужно больше всего

Windows с потребительскими видеокартами (GeForce GTX/RTX, Radeon RX, Intel Arc и встроенные Iris/UHD) на распространённых разрешениях — 1920×1080, 2560×1440, 1366×768. Ноутбуки со встроенным экраном. macOS на M1–M4 разных лет. Одинаковое железо даёт одинаковую персону, так что ценна каждая другая конфигурация, а не каждый человек.
